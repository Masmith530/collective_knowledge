# Collective Knowledge

Free pilot training resources for student pilots — ground school lessons, study guides, and curated links. Helicopter-first, with fixed-wing content as the library grows.

## Local preview

Open `index.html` in a browser, or run a local server:

```bash
python3 -m http.server 8080
```

Then visit [http://localhost:8080](http://localhost:8080).

## Project structure

```
collective_knowledge/
├── index.html          # Home page
├── 404.html            # Custom not-found page
├── css/styles.css      # Shared styles
├── js/main.js          # Footer year
└── assets/             # Favicon, images, etc.
```

## Deploy to GitHub Pages

1. Push to a GitHub repo
2. Go to **Settings → Pages**
3. Set **Source** to branch **main**, folder **/ (root)**
4. Save — site goes live at your GitHub Pages URL in a minute or two
